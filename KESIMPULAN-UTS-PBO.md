KESIMPULAN UTS PEMROGRAMAN BERORIENTASI OBJEK

1. Pendahuluan

Tugas Ujian Tengah Semester (UTS) ini dibuat untuk menerapkan materi yang telah dipelajari dalam mata kuliah Pemrograman Berorientasi Objek (PBO).

2. Hasil Pembelajaran

Melalui pengerjaan tugas ini, saya mempelajari:

- Dasar-dasar bahasa pemrograman Python.
- Algoritma dan flowchart.
- Variabel, tipe data, dan operator.
- Percabangan, perulangan, dan fungsi.
- Konsep Class dan Object.
- Constructor, Method, Inheritance, dan Polymorphism.
- Penggunaan library Pygame.

3. Hasil Project

Project utama yang dibuat adalah Game Balapan Mobil menggunakan Python dan Pygame. Game memiliki menu utama, pilihan level, tiga jalur balapan, mobil pemain, mobil musuh, koin, sistem skor, dan Game Over.

4. Kesimpulan

Dari pengerjaan tugas UTS PBO ini, saya memperoleh pemahaman lebih baik mengenai pemrograman Python dan penerapan konsep Object-Oriented Programming. Saya juga belajar membuat project sederhana serta menyimpan dan mendokumentasikan hasil pekerjaan melalui GitHub.

5. Penutup

Demikian repository tugas UTS Pemrograman Berorientasi Objek ini dibuat sebagai dokumentasi hasil pembelajaran dan praktik selama perkuliahan.
