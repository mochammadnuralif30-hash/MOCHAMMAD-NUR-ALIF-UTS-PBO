3. VARIABEL DAN TIPE DATA

A. Pengertian Variabel

Variabel adalah tempat untuk menyimpan data atau nilai di dalam program. Variabel digunakan agar data dapat dipanggil dan diolah kembali.

B. Aturan Penulisan Variabel

1. Nama variabel tidak boleh diawali angka.
2. Tidak boleh menggunakan spasi.
3. Tidak boleh menggunakan kata kunci Python.
4. Penulisan variabel membedakan huruf besar dan kecil.

C. Pengertian Tipe Data

Tipe data adalah jenis nilai yang digunakan dalam sebuah program.

Jenis tipe data Python:

1. Integer (int): Bilangan bulat.
2. Float: Bilangan desimal.
3. String (str): Teks atau kumpulan karakter.
4. Boolean (bool): Nilai True atau False.
5. List: Kumpulan data yang dapat diubah.

D. Contoh Program Python

nama = "Alif"
umur = 20
tinggi = 170.5
mahasiswa = True

print("Nama:", nama)
print("Umur:", umur)
print("Tinggi:", tinggi)
print("Mahasiswa:", mahasiswa)

E. Kesimpulan

Variabel digunakan untuk menyimpan data, sedangkan tipe data menentukan jenis nilai yang disimpan. Keduanya merupakan dasar penting dalam pembuatan program Python.
