8. LIST DAN TUPLE PYTHON

A. Pengertian List

List adalah tipe data Python yang digunakan untuk menyimpan beberapa nilai dalam satu variabel. List ditulis menggunakan tanda kurung siku [].

B. Ciri-Ciri List

1. Dapat menyimpan banyak data.
2. Data dapat diubah atau ditambahkan.
3. Dapat menyimpan berbagai tipe data.
4. Urutan data tetap sesuai indeks.

C. Contoh Program List

buah = ["Apel", "Jeruk", "Mangga"]

print(buah)
print(buah[0])

buah.append("Pisang")
print(buah)

D. Pengertian Tuple

Tuple adalah tipe data Python yang digunakan untuk menyimpan beberapa nilai dalam satu variabel. Tuple ditulis menggunakan tanda kurung () dan datanya tidak dapat diubah setelah dibuat.

E. Ciri-Ciri Tuple

1. Dapat menyimpan banyak data.
2. Data tidak dapat diubah.
3. Memiliki urutan berdasarkan indeks.
4. Dapat menyimpan berbagai tipe data.

F. Contoh Program Tuple

warna = ("Merah", "Biru", "Hijau")

print(warna)
print(warna[1])

G. Perbedaan List dan Tuple

List| Tuple
Menggunakan []| Menggunakan ()
Data dapat diubah| Data tidak dapat diubah
Lebih fleksibel| Lebih tetap

H. Kesimpulan

List dan Tuple merupakan tipe data untuk menyimpan banyak nilai dalam satu variabel. Perbedaannya adalah List dapat diubah, sedangkan Tuple tidak dapat diubah setelah dibuat.
