1. PENGENALAN PYTHON

A. Pengertian Python

Python adalah bahasa pemrograman tingkat tinggi yang memiliki sintaks sederhana sehingga mudah dipelajari oleh pemula. Python dapat digunakan untuk membuat aplikasi, mengolah data, mengembangkan website, kecerdasan buatan, dan permainan.

B. Sejarah Singkat Python

Python dikembangkan oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Python dirancang agar mudah dibaca, dipahami, dan digunakan oleh programmer.

C. Kelebihan Python

1. Memiliki sintaks yang sederhana.
2. Mudah dipelajari oleh pemula.
3. Dapat digunakan pada berbagai sistem operasi.
4. Memiliki banyak library.
5. Mendukung pemrograman prosedural dan berorientasi objek.

D. Fungsi Python

Python dapat digunakan untuk:

- Membuat aplikasi desktop.
- Membuat website.
- Mengolah data.
- Membuat game.
- Mengembangkan kecerdasan buatan.

E. Contoh Program Python

Contoh program sederhana untuk menampilkan tulisan:

print("Hello World")
print("Belajar Pemrograman Python")

Hasil output:

Hello World
Belajar Pemrograman Python

F. Kesimpulan

Python merupakan bahasa pemrograman yang mudah dipelajari dan memiliki banyak kegunaan. Dengan memahami dasar Python, kita dapat melanjutkan pembelajaran ke materi algoritma, struktur data, dan Pemrograman Berorientasi Objek (PBO).
