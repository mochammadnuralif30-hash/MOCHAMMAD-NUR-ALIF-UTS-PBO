4. OPERATOR DALAM PYTHON

A. Pengertian Operator

Operator adalah simbol yang digunakan untuk melakukan operasi terhadap nilai atau variabel dalam pemrograman Python.

B. Jenis-Jenis Operator

1. Operator Aritmatika

Digunakan untuk melakukan perhitungan matematika.

- (+) Penjumlahan
- (-) Pengurangan
- (*) Perkalian
- (/) Pembagian
- (%) Modulus atau sisa bagi
- (**) Pangkat
- (//) Pembagian bulat

2. Operator Perbandingan

Digunakan untuk membandingkan dua nilai.

- (==) Sama dengan
- (!=) Tidak sama dengan
- (>) Lebih besar
- (<) Lebih kecil
- (>=) Lebih besar atau sama dengan
- (<=) Lebih kecil atau sama dengan

3. Operator Logika

Digunakan untuk menggabungkan kondisi.

- and: Kedua kondisi harus benar.
- or: Salah satu kondisi harus benar.
- not: Membalik nilai logika.

4. Operator Penugasan

Digunakan untuk memberikan atau memperbarui nilai variabel.

- (=) Memberikan nilai
- (+=) Menambahkan nilai
- (-=) Mengurangi nilai
- (*=) Mengalikan nilai
- (/=) Membagi nilai

C. Contoh Program Python

a = 10
b = 5

print("Penjumlahan:", a + b)
print("Pengurangan:", a - b)
print("Perkalian:", a * b)
print("Pembagian:", a / b)
print("Sisa bagi:", a % b)

print("Perbandingan:", a > b)
print("Logika:", a > 5 and b < 10)

D. Kesimpulan

Operator merupakan bagian penting dalam Python yang digunakan untuk melakukan perhitungan, membandingkan nilai, mengolah kondisi logika, dan memberikan nilai pada variabel.
