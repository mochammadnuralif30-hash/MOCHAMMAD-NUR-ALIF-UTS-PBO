6. PERULANGAN DALAM PYTHON

A. Pengertian Perulangan

Perulangan atau looping adalah proses menjalankan suatu perintah secara berulang selama kondisi tertentu terpenuhi. Perulangan digunakan untuk menghindari penulisan kode yang sama berkali-kali.

B. Jenis-Jenis Perulangan

1. For

Perulangan for digunakan untuk mengulang perintah berdasarkan jumlah data atau urutan tertentu.

2. While

Perulangan while digunakan untuk menjalankan perintah selama kondisi bernilai True.

C. Fungsi Perulangan

1. Mengulang perintah secara otomatis.
2. Menghemat penulisan kode.
3. Mempermudah pengolahan data.
4. Menjalankan proses berulang berdasarkan kondisi.

D. Contoh Perulangan For

for i in range(1, 6):
    print("Perulangan ke-", i)

Hasil output:

Perulangan ke- 1
Perulangan ke- 2
Perulangan ke- 3
Perulangan ke- 4
Perulangan ke- 5

E. Contoh Perulangan While

angka = 1

while angka <= 5:
    print("Angka:", angka)
    angka += 1

F. Perintah Break dan Continue

- Break: Menghentikan perulangan.
- Continue: Melewati satu proses dan melanjutkan perulangan berikutnya.

G. Kesimpulan

Perulangan digunakan untuk menjalankan perintah secara berulang. Python menyediakan perulangan for dan while yang dapat digunakan sesuai kebutuhan program.
