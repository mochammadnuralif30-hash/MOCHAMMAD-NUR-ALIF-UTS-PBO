2. ALGORITMA DAN FLOWCHART

A. Pengertian Algoritma

Algoritma adalah urutan langkah-langkah yang logis dan sistematis untuk menyelesaikan suatu masalah. Dalam pemrograman, algoritma digunakan sebagai dasar sebelum membuat sebuah program.

B. Ciri-Ciri Algoritma

1. Memiliki langkah yang jelas.
2. Memiliki urutan yang sistematis.
3. Memiliki input dan output.
4. Langkah-langkahnya harus berakhir.
5. Dapat menyelesaikan suatu permasalahan.

C. Pengertian Flowchart

Flowchart atau diagram alir adalah gambaran visual yang menunjukkan urutan proses atau langkah-langkah dalam suatu algoritma menggunakan simbol tertentu.

D. Simbol Flowchart

1. Terminal (Oval): Menunjukkan awal dan akhir program.
2. Process (Persegi Panjang): Menunjukkan proses pengolahan data.
3. Input/Output (Jajar Genjang): Menunjukkan proses masukan dan keluaran.
4. Decision (Belah Ketupat): Menunjukkan percabangan atau keputusan.
5. Flowline (Panah): Menunjukkan arah alur proses.

E. Contoh Algoritma Sederhana

Menentukan bilangan genap atau ganjil.

Langkah-langkah:

1. Mulai.
2. Masukkan sebuah bilangan.
3. Periksa apakah bilangan habis dibagi 2.
4. Jika iya, tampilkan Genap.
5. Jika tidak, tampilkan Ganjil.
6. Selesai.

F. Contoh Program Python

angka = int(input("Masukkan angka: "))

if angka % 2 == 0:
    print("Bilangan Genap")
else:
    print("Bilangan Ganjil")

G. Kesimpulan

Algoritma membantu programmer menyusun langkah penyelesaian masalah secara teratur, sedangkan flowchart membantu menggambarkan alur algoritma agar lebih mudah dipahami sebelum diterapkan menjadi program.
