GAME BALAPAN MOBIL

1. Deskripsi Program

Game Balapan Mobil merupakan permainan sederhana berbasis Python menggunakan library Pygame. Pemain mengendalikan mobil untuk menghindari mobil musuh dan mengumpulkan koin.

2. Tujuan Game

- Menghindari tabrakan dengan mobil musuh.
- Mengumpulkan koin sebanyak mungkin.
- Mendapatkan skor tertinggi.
- Menyelesaikan permainan dengan tingkat kesulitan yang dipilih.

3. Fitur Game

- Menu utama.
- Tiga pilihan level: Easy, Medium, dan Hard.
- Tiga jalur lintasan.
- Mobil pemain dan mobil musuh.
- Koin untuk menambah skor.
- Sistem tabrakan.
- Tampilan skor.
- Game Over.
- Pilihan Restart dan Back to Menu.

4. Kontrol Permainan

Tombol| Fungsi
Panah Kiri| Menggerakkan mobil ke kiri
Panah Kanan| Menggerakkan mobil ke kanan
Mouse| Memilih menu dan level

5. Teknologi yang Digunakan

- Bahasa pemrograman Python.
- Library Pygame.
- Konsep Object-Oriented Programming (OOP).

6. Konsep PBO

Program menggunakan beberapa konsep PBO:

- Class: Car dan Coin.
- Object: Objek mobil dan koin.
- Constructor: Mengatur atribut awal objek.
- Method: Mengatur gerakan dan tampilan objek.

7. Cara Instalasi

Install library Pygame dengan perintah:

pip install pygame

8. Cara Menjalankan Game

Jalankan perintah:

python 05-Game-Balapan-Mobil.py

9. Kesimpulan

Game Balapan Mobil dibuat untuk menerapkan dasar Python dan konsep Object-Oriented Programming dalam sebuah permainan sederhana.
