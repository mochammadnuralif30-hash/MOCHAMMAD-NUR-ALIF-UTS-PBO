DAFTAR PROJECT PYTHON

Repository ini berisi kumpulan program dan project yang dibuat untuk memenuhi tugas UTS Pemrograman Berorientasi Objek (PBO).

Daftar Program

1. Program Python Dasar

File: "01-Program-Python-Dasar.py"

2. Program Algoritma dan Percabangan

File: "02-Program-Algoritma-dan-Percabangan.py"

Materi: Algoritma, perhitungan nilai, dan percabangan if-elif-else.

3. Program Perulangan dan Fungsi

File: "03-Program-Perulangan-dan-Fungsi.py"

Materi: Perulangan, fungsi, total nilai, dan rata-rata.

4. Program OOP Mahasiswa

File: "04-Program-OOP-Mahasiswa.py"

Materi: Class, object, constructor, atribut, dan method.

5. Game Balapan Mobil

File: "05-Game-Balapan-Mobil.py"

Materi: Penerapan OOP menggunakan Python dan Pygame.

Tujuan

Mengembangkan pemahaman pemrograman Python, algoritma, dan konsep Object-Oriented Programming melalui latihan program dan pembuatan game.
