HASIL PENGUJIAN GAME BALAPAN MOBIL

1. Tujuan Pengujian

Pengujian dilakukan untuk memastikan Game Balapan Mobil dapat berjalan dengan baik sesuai fitur yang telah dibuat.

2. Lingkungan Pengujian

- Bahasa pemrograman: Python
- Library: Pygame
- Editor: Visual Studio Code

3. Hasil Pengujian

No.| Fitur yang Diuji| Hasil
1| Menampilkan menu utama| Berhasil
2| Memilih level permainan| Berhasil
3| Menggerakkan mobil pemain| Berhasil
4| Menampilkan mobil musuh| Berhasil
5| Mengumpulkan koin| Berhasil
6| Menghitung skor| Berhasil
7| Mendeteksi tabrakan| Berhasil
8| Menampilkan Game Over| Berhasil
9| Restart permainan| Berhasil
10| Kembali ke menu utama| Berhasil

4. Kesimpulan

Berdasarkan pengujian yang telah dilakukan, Game Balapan Mobil dapat dijalankan menggunakan Python dan Pygame. Fitur-fitur permainan dapat digunakan sesuai dengan fungsi yang telah dibuat.
